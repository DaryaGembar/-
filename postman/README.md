# Postman коллекция — PizzaEat API

Postman-коллекция для тестирования API учебного магазина [«Пиццаед»](https://aiqa.su/base/shop).

## Как использовать

### 1. Импорт в Postman

1. Открой Postman
2. **File → Import** → выбери `PizzaEat.postman_collection.json`
3. Коллекция появится в боковой панели

### 2. Настрой окружение

1. Создай **Environment** с переменными:
   - `base_url` = `https://aiqa.su`
   - `session_id` = любой UUID (например, через https://uuidgenerator.net)
2. Выбери это окружение в правом верхнем углу

### 3. Запусти сценарий

- Папка « E2E Сценарий» — готовая цепочка из 5 запросов
- Запусти через **Collection Runner** (правая кнопка мыши → Run folder)

## Что внутри

| Папка        | Запросов | Назначение                      |
| ------------ | -------- | ------------------------------- |
| Products     | 6        | Каталог, фильтры, 404           |
| Cart         | 7        | Добавить/изменить/удалить товар |
| Orders       | 4        | Создать заказ с/без промокода   |
| E2E Сценарий | 5        | Полный путь пользователя        |

## Тесты

Каждый запрос содержит **pm.test** проверки:

- Status code (200, 201, 422)
- Структура ответа (наличие обязательных полей)
- Бизнес-правила (промокод, доставка, наличие товара)

## Что покрыто

- ✅ CRUD для продуктов и корзины
- ✅ Бизнес-правила промокода QA60 (10%, case-insensitive, trim)
- ✅ Расчёт доставки (199₽ / бесплатно)
- ✅ Out-of-stock товар (Чизкейк)
- ✅ Невалидные данные (quantity вне диапазона, пустая корзина)

## Что не покрыто

- Security тесты (XSS, SQL injection) — добавлю позже
- Performance тесты — выходит за рамки ручного API
- Контрактные тесты через Pact — для этого проекта overkill
